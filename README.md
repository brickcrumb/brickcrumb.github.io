# Календарь олимпиад

Статический сайт со списком олимпиад по математике и датами событий.
Работает на GitHub Pages, данные — в `data.json`.

## Как обновить данные

1. Открой `data.json` в репозитории на GitHub → нажми ✏️ (Edit).
2. Добавь новое событие в массив (не забудь запятую между объектами).
3. Нажми **Commit changes**.
4. Через 1–2 минуты сайт обновится.

```json
{
  "olympiad": "Название олимпиады",

  "date_start": "2026-03-22",
  "date_end": null,
  "classes": "5–11",
  "format": "очно | онлайн",
  "url": "https://сайт-олимпиады",
  "prep_url": "https://ссылка-на-подготовку",

}
